## 🚀 如何使用

### 步骤1：启动后端服务

```bash
cd <repo-root>/backend
uvicorn app.main:app --reload --port 8000
```

### 步骤2：启动前端服务（新开终端）

```bash
cd <repo-root>/frontend
npm run dev
```

### 步骤3：访问简历编辑器

打开浏览器，访问：
```
http://localhost:3000/resume-editor
```

## 🔧 技术实现

### 后端API新增接口

#### 1. 采集指定平台数据
```
POST /api/resume-editor/collect/{platform}
```

**支持的平台：**
- `boss` - BOSS直聘
- `liepin` - 猎聘网
- `51job` - 51job
- `zhilian` - 智联招聘

**返回：**
```json
{
  "success": true,
  "message": "boss数据采集成功",
  "output": "采集脚本输出..."
}
```

#### 2. 采集所有平台数据
```
POST /api/resume-editor/collect-all
```

**返回：**
```json
{
  "success": true,
  "data": {
    "boss": {"success": true, "message": "采集成功"},
    "liepin": {"success": true, "message": "采集成功"},
    "51job": {"success": true, "message": "采集成功"},
    "zhilian": {"success": true, "message": "采集成功"}
  }
}
```

## 💡 使用场景

### 场景1：首次使用
1. 打开前端页面
2. 点击"采集所有平台"按钮
3. 等待采集完成
4. 查看采集到的数据

### 场景2：更新数据
1. 打开前端页面
2. 点击"采集BOSS数据"或"采集所有平台"
3. 等待采集完成
4. 数据自动更新

### 场景3：查看数据
1. 打开前端页面
2. 数据自动加载
3. 切换不同平台查看
4. 编辑字段（待实现）

## 🐛 常见问题

### Q1：点击采集按钮没有反应？
**A1**：检查后端服务是否启动，查看控制台错误信息。

### Q2：采集超时？
**A2**：采集脚本可能需要较长时间，请耐心等待或检查网络连接。

### Q3：数据没有显示？
**A3**：点击"刷新数据"按钮，或检查后端API是否正常。

### Q4：如何重新采集？
**A4**：点击"采集BOSS数据"或"采集所有平台"按钮即可。
