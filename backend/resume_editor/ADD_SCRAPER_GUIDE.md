# BOSS直聘期望职位分类爬取器（添加按钮版本）- 使用说明

## 📋 脚本说明

这个脚本会：
1. 访问BOSS直聘简历页面
2. 点击期望职位的"添加"按钮
3. 遍历二级分类，记录名称
4. 点击每个二级分类，遍历三级分类，记录名称
5. 保存到JSON文件

---

## 🚀 使用步骤

### 步骤1：运行脚本

```bash
cd <repo-root>/backend
python3 resume_editor/platforms/boss_add_scraper.py
```

### 步骤2：手动登录（如果需要）

脚本会检查登录状态，如果未登录，会提示你手动扫码登录。

### 步骤3：等待脚本完成

脚本会自动遍历所有分类，并实时输出进度：

```
📁 二级分类: 后端开发
   📄 三级分类: 首席技术官CTO
   📄 三级分类: 技术总监/经理
   📄 三级分类: 项目总监
   📄 三级分类: 项目主管
   📄 三级分类: 项目组长
   📄 三级分类: 其他技术职位

📁 二级分类: 前端开发
   📄 三级分类: Web前端
   📄 三级分类: JavaScript
   📄 三级分类: HTML5
   📄 三级分类: Flash
   📄 三级分类: 其他

📁 二级分类: 移动开发
   📄 三级分类: Android
   📄 三级分类: iOS
   📄 三级分类: 其他
```

### 步骤4：查看结果

脚本会保存到：
```
backend/resume_editor/data/boss_add_categories.json
```

## 🎯 优势

1. **完全一致** - 所有分类名称与BOSS官网完全一致
2. **不会遗漏** - 自动遍历所有分类
3. **自动记录** - 不需要手动比对
4. **后期同步** - 同步回BOSS官网时，名称完全匹配

---

## 🔧 技术细节

### 使用的工具
- **DrissionPage** - 浏览器自动化
- **Edge浏览器** - 与BOSS直聘兼容

### 等待时间
- 点击"添加"按钮后等待10秒
- 点击二级分类后等待2秒
- 确保动态加载的内容完全加载

### 错误处理
- 如果某个分类获取失败，会记录错误并继续
- 确保不会因为单个错误而中断整个流程
