## 登录态方案演进

### ❌ 方案 1：Edge CDP 端口连接（已废弃）
- 启动 Edge 浏览器（端口 9227），Playwright 通过 CDP 连接
- **问题**：登录态不稳定，新标签页丢失登录，51job 检测到自动化环境

### ❌ 方案 2：Playwright Chromium + cookie 注入（已废弃）
- 用 `browser_cookie3` 读取 cookie，注入到 Playwright Chromium
- **问题**：`jobs.51job.com` 岗位详情页触发滑动验证码（Chromium 指纹被检测）

### ✅ 方案 3：Edge Profile + cookie 注入（当前方案）
- 用 Playwright 的 `launch_persistent_context` 启动 Edge + 用户真实 Profile
- 注入 `browser_cookie3` 从日常浏览器读取的 cookie
- **优点**：Edge 指纹正常，简历中心操作不触发验证码
- **遗留问题**：`jobs.51job.com` 域名的岗位详情页仍触发验证码

## 踩坑记录

### 1. Element UI 输入框 fill() 不生效
- **现象**：`input.fill('xxx')` 后值没变
- **原因**：Vue 的 v-model 不检测程序化的 value 修改
- **解决**：用 JS 设置值 + dispatch input/change 事件
```python
page.evaluate('''(args) => {
    const input = document.querySelector('input.el-input__inner');
    const setter = Object.getOwnPropertyDescriptor(window.HTMLInputElement.prototype, 'value').set;
    setter.call(input, args.name);
    input.dispatchEvent(new Event('input', { bubbles: true }));
    input.dispatchEvent(new Event('change', { bubbles: true }));
}''', {"name": new_value})
```

### 2. 重命名弹窗找不到输入框
- **现象**：弹窗出现了但 `page.query_selector('input.el-input__inner')` 返回 None
- **原因**：页面上有多个 `el-dialog__wrapper`，代码找到了隐藏的那个
- **解决**：改为等待「确定」按钮出现（只在弹窗里），再用 JS 找所有可见 input

### 3. 频繁刷新触发滑动验证码
- **现象**：操作过程中弹出「请向右滑动滑块」
- **原因**：页面刷新间隔太短（<5秒）
- **解决**：用等待替代轮询，操作间隔至少 5-10 秒，审核等待改为固定等待 25 秒

### 4. 上传后需要点「确认添加」
- **现象**：文件上传成功但简历没出现在列表
- **原因**：上传弹窗需要点「确认添加」才能保存，不是关闭弹窗
- **解决**：`page.query_selector('text=确认添加').click()`

### 5. jobs.51job.com 域名触发验证码
- **现象**：直接访问 `jobs.51job.com/xxx.html` 弹出滑动验证码
- **原因**：旧域名反爬更严格
- **解决**：URL 转换为 `we.51job.com/pc/search/jobdetail?jobid=xxx`

### 6. 51job 打招呼语字段可选
- **现象**：飞书表里打招呼语为空时，`get_jobs_to_deliver()` 跳过该记录
- **原因**：51job 投递不需要打招呼语（跟猎聘不同）
- **解决**：修改验证逻辑，51job 平台不要求 greeting 字段

## 待解决的问题

1. **每日上传次数限制**：51job 附件简历有每日上传上限，需要考虑批量投递时的限流策略
2. **岗位详情页验证码**：`jobs.51job.com` 和 `we.51job.com` 的岗位详情页都可能触发滑动验证码，需要进一步研究规避方案
3. **简历数量上限**：最多 3 份附件简历，超过需删除旧的
