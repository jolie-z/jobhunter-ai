设计亮点

几个值得深思的
核心架构决策

这些并不是冷冰冰的功能参数，而是这个自动化系统「为什么好用、为什么敢放心用」的根本基石。

手机就是指挥台

在飞书聊天框用自然语言直接下指令：「查进度」「找找算法工程师」「看最新 A 级岗位」——背后由 16 个原子工具实现精准意图解析与 SSE 日志回流。长连接机器人免公网 IP；岗位截图发进群，OCR 识别、八维评估、定制简历一键推送。

数据绝不出本机

浏览器登录态 Profile、SQLite 数据库母本、各平台 API 密钥全部只加密保存在本地，不收集、不上传任何个人数据。GPL-3.0 协议全开源，每一行代码都经得起独立审计。求职与简历这种最隐私的数据，必须完全掌控在自己手里。

Token 永远花在刀刃上

岗位清洗先走 0 Token 硬规则（城市 / 学历 / 资历 / 薪资毫秒级初筛），只有评为 A / B 级的优质岗位才触发模型深度体检；主 / 清洗 / 视觉三通道模型矩阵各司其职；KV Cache 命中机制使 Token 成本直降约 70%，大盘中每次调用均可审计计价。

工程质量三道严格门禁

1000+ 后端自动化测试（覆盖 143 个测试文件）+ 前端测试矩阵全绿；每次关键代码变更均经过独立 Reviewer 双轴严格审查才允许合入；模块级 QA 对账报告全部留痕存证。唯有扎实的自动化门禁，才能赋予使用者「放心把手松开」的底气。

① 启动 Python 后端

Python 3.10+，推荐使用 uv 工具管理；初次启动需安装 Playwright 依赖
# 进入 backend/ 目录
uv sync
cp .env.example .env   # 按需配置飞书与 LLM 密钥
playwright install chromium
uvicorn app.main:app --reload
# → http://localhost:8000 (API 就绪)

② 启动 Next.js 前端

Node.js 18+；Windows 用户可直接双击根目录下 start_all.bat
# 进入 frontend/ 目录
npm install
npm run dev
# → http://localhost:3000 (控制台就绪)

③ 接入飞书生态（推荐）

9 步手册：创建应用 → 开启长连接 → 绑定多维表格 → 一键校验配置
# 一键测试所有配置与密钥是否生效
python scripts/test_config_validation.py all

# ChatOps 自然语言指令批量自测验证
python backend/test_scripts/test_feishu_chatops.py --batch

④ 生产环境 PM2 守护

爬虫依赖真实浏览器 Profile，推荐宿主机常驻搭配 PM2 自愈
pm2 start "uvicorn app.main:app --host 0.0.0.0 --port 8000" --name jobhunter-api --cwd backend
pm2 start "npm start" --name jobhunter-web --cwd frontend
飞书完整接入指南：docs/feishu-setup.md（含常见问题 FAQ）· 详细字段配置说明见仓库 README。
